# Muhammad Faizan Javaid — Portfolio Website

Responsive, single-page HTML/CSS/JavaScript portfolio. No build tools required.

## Open locally

Open `index.html` in a browser. The profile photo and downloadable CV are bundled in `assets/`.

## Publish free with GitHub Pages

1. Create a public GitHub repository (for example `portfolio`).
2. Upload `index.html` and the complete `assets/` folder.
3. Go to repository **Settings → Pages → Build and deployment**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, and save.
5. Your website will appear at `https://YOUR_USERNAME.github.io/portfolio/`.

## Customize

- Edit text, links, and colors directly in `index.html`.
- Replace `assets/faizan.jpg` to change the hero portrait.
- Replace `assets/Faizan_Javaid_CV.pdf` to update the resume.
- Case studies are in the `cases` object near the end of `index.html`.
- Replace `[ADD METRIC]` placeholders only with verified evidence.

The contact buttons open the visitor's email application; they do not submit information to a server.
